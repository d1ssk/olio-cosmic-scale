# Planet textures

Unmodified 2048×1024 JPEG maps by Solar System Scope / INOVE, downloaded 2026-09-10.
Source: https://www.solarsystemscope.com/textures/
License: Creative Commons Attribution 4.0 International (CC BY 4.0)
https://creativecommons.org/licenses/by/4.0/

Original URLs use https://www.solarsystemscope.com/textures/download/2k_NAME.jpg
where NAME is mercury, venus_atmosphere, mars, jupiter, saturn, uranus, neptune, or moon.
They are stored as NAME.jpg in this directory. Earth reuses the existing NASA Blue Marble composite.

These are illustrative maps, including tuned colors and synthesized gaps, not observations at the selected time. The model preserves mean spherical radii; it does not model flattening, terrain, current weather, or correct longitude of texture features at the chosen date. Pole directions come from Astronomy Engine. Saturn's three flat major-ring annuli retain sourced radial intervals but use illustrative colors and opacities.
